Samantha is your in-app assistant in MySamantha. She helps you manage notes, tasks, journals, email, calendar, and more from one connected workspace.

You can ask Samantha to capture information, find what matters, turn conversations into actions, and help you follow through. Samantha only acts when you ask.

## What is Samantha?

Samantha is a conversational assistant built into MySamantha.

## What Samantha helps with

Creating notes, tasks, and journal entries, retrieving past context, summarizing information, drafting messages, and helping you move from ideas to action.

## How it works

You ask in natural language, Samantha understands the request, finds the right context, and helps you take the next step.

## How to use Samantha

1. Open Samantha in MySamantha
2. Type a message or use voice input
3. Ask in plain language
4. Review the result or suggested action
5. Approve when needed
6. Continue the conversation if you want to refine it

You do not need special commands or rigid formats.

## What Samantha can help with

Samantha can support both personal and work workflows from one place.

- Create notes, to dos, and journal entries
- Edit, rewrite, or summarize existing content
- Retrieve past notes, tasks, and conversations
- Turn rough thoughts into structured actions
- Help across connected tools like email, calendar, and maps

## Conversations to actions

One of Samantha’s main strengths is turning chat into action.

## Common examples

- A thought can become a note
- A plan can become a task list
- A follow-up can become a reminder
- A date you mention can become a calendar event
- A rough message can become a draft email

This helps you move faster without switching tools or rewriting things manually.

## Memory and context

Samantha keeps track of relevant context across your workspace.

## Samantha can remember

- Previous chats
- Related notes and tasks
- Past decisions and references

This makes follow-up conversations easier because you do not need to repeat everything from scratch.

## Smart recall

When needed, Samantha can search your workspace and bring back useful context.

## How it works

- Samantha searches your notes, journals, tasks, and chats
- Relevant information is surfaced automatically
- You can continue from where you left off

This helps maintain continuity over time.

## Integrations support

When integrations are connected, Samantha can work across your tools from the same conversation.

## Samantha can help with

- Email\
  Summarize emails, draft replies, find follow-ups, and turn messages into tasks or events
- Calendar\
  Review your schedule, create events, and plan around upcoming meetings
- Maps\
  Use location context for planning, places, and travel coordination
- Slack\
  Send messages, summarize threads, find updates, and turn conversations into notes or tasks
- HubSpot\
  Find contacts, review deals, update records, add notes, and support follow-up workflows
- Eventbrite\
  Review events, check registrations, summarize event details, and organize follow-up work
- Linear\
  Find issues, create tickets, review status, and turn discussions into actionable work
- Notion\
  Find pages, summarize docs, create content, and pull action items from workspace content
- GitHub\
  Review repositories, find issues or pull requests, create issues, and summarize project activity
- Cloudflare\
  Review domains, inspect DNS records, summarize setup details, and support website operations

All integrations are optional and permission-based.

## Files and chat sharing

Samantha keeps shared files and conversations accessible when you need them.

## Files

- Every file you send in chat is saved automatically
- You can browse, search, and reopen files later
- Supported file types include images, documents, and PDFs

## Share chat

- Create a share link for a conversation
- Choose whether the link stays updated
- Choose whether attachments are included
- Delete a link anytime if you no longer want it active

Sharing is always optional and permission-based.

## Offline behavior

When offline:

- Notes, to dos, and journals still work
- Samantha chat and AI actions are unavailable

Everything syncs once you reconnect.

## Tips for using Samantha

## Ask naturally

You do not need to phrase things in a special way. Simple requests work best.

## Start with rough input

Even incomplete thoughts are useful. Samantha can help structure them.

## Use follow-up questions

You can keep refining the same conversation instead of starting over.

## Let Samantha connect the dots

Ask Samantha to pull from notes, tasks, chats, and connected tools when context matters.

## Review before action

For drafts, saved content, or external actions, review before approving.
