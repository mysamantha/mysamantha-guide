Samantha is your in-app assistant in MySamantha. She helps you manage notes, tasks, journals, email, calendar, and more from one connected workspace.

You can ask Samantha to capture information, find what matters, turn conversations into actions, and help you follow through.

<Note>
  Samantha only acts when you ask.
</Note>

## Talking to Samantha

You can interact with Samantha in natural language.

You can:

- Type messages
- Use voice input
- Continue conversations over time

You do not need special commands or rigid formatting.

## Conversations to Actions

Samantha can turn chat into structured actions.

**For example:**

- A thought can become a note
- A plan can become a task list
- A follow-up can become a reminder
- A date you mention can become a calendar event
- A rough message can become a draft email

## Memory & Context

Samantha maintains context across conversations.

Samantha can remember:

- Previous chats
- Related notes and tasks
- Past decisions and references

This allows follow-ups without repeating yourself.

## Smart Recall

Samantha finds relevant past information when needed.

**How it works**

- Samantha searches your notes, journals, tasks, and chats
- Relevant context is surfaced automatically

This helps maintain continuity over time.

## Writing and Drafting

Samantha can help you write with review control.

Samantha can:

- Draft emails
- Rewrite or refine text
- Generate summaries or explanations

Nothing is sent or saved without your approval.

## Image Generation

Create images inside Samantha using natural language. Describe what you want, and Samantha can generate visuals to support ideas, content, and creative work.

### What image generation helps you do

- Generate images from natural language prompts
- Explore visual ideas quickly
- Create simple visuals for content, planning, or creative work
- Refine prompts and try different directions in chat

### How it works

Ask Samantha for the image you want to create. You can describe the subject, style, mood, or use case in plain language.

Samantha will generate images based on your prompt.

### Example prompts

```text
Create an image of a calm modern workspace.

Generate a simple hero image for a landing page.

Make an illustration for a product update post.

Create 3 visual directions for a homepage concept.
```

### Review and control

Image generation happens only when you ask. You stay in control of the prompt and can refine it based on the result.

## Files

Files gives you a single place to access everything you have shared with Samantha.

### How it works

- Every file you send in chat is saved automatically
- You can browse, search, and reopen any file anytime
- Files are organized and accessible from the Files section in the assistant

### Supported file types

- Images
- Documents
- PDFs
- Other file types shared in chat

No need to re-upload. Once shared, it is always there.

## Share Chat

Share a conversation when someone else needs the context, decisions, or next steps.

You can:

- Create a share link for a chat
- Choose whether it stays auto-updated as the conversation continues
- Choose whether to include attachments

### Links and limits

- Each chat can have up to 5 active share links at a time
- Delete a link anytime to free up a slot

### Privacy and control

- Sharing is always optional and permission-based
- Nothing is shared without your approval
- Share links can be deleted at any time

## Offline Behavior

When offline:

- Notes, to-do, and journals still work
- Samantha chat and AI actions are unavailable

Everything syncs once you reconnect.
