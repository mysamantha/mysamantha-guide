## Create notes

You can create notes in multiple ways:

- Type directly in Notes
- Record a voice note and let Samantha transcribe it
- Ask Samantha in chat to create a note for you

## Voice to Note

Use voice when you want to capture something quickly.

**How to use**

1. Tap the microphone
2. Speak naturally
3. Your note is transcribed and saved automatically

## Slash commands

Type `/` inside a note to open formatting options, insert elements, and note actions without leaving the editor.

## Labels

Labels help you organize notes by topic, project, or workflow.

**How to use**

- Create custom labels
- Apply one or more labels to a note
- Search or filter notes using labels

## Atlas

See your notes as a visual knowledge map.

Atlas turns your notes into an interactive graph so you can explore how ideas connect, spot important notes, and navigate your knowledge visually instead of scrolling through a list.

<video src="videos/atlas.mp4" controls />

### What it shows

- Each dot is a note
- A hub is a note with many connections
- Each line is a link between notes
- A pending item is a link to a note that has not been created yet

### What you can do

- View all notes in one visual space
- Open a note directly from the graph
- Spot connected ideas and important hubs
- Search notes inside Atlas
- Use the mini-map to navigate large note collections
- Group notes visually
- Adjust layout and display settings for readability

### How to use

1. Open Notes
2. Open Atlas
3. Click any node to open that note
4. Use search to find a note in the graph
5. Use the controls panel to tune the view

### Groups

Groups let you color notes by matching rules so related notes are easier to spot.

**How groups work**

- Group notes by **Label**, **Title**, or **Keyword**
- Group order matters, so you can drag groups to change priority
- Create groups to visually separate projects, topics, or workflows

### Display

Use display controls to make Atlas easier to scan.

- **Arrows**\
  Show or hide direction on links
- **Text fade threshold**\
  Controls when note labels fade based on zoom level or density
- **Node size**\
  Makes note dots bigger or smaller
- **Link thickness**\
  Makes connections thicker or thinner
- **Animate**\
  Adds motion while the graph arranges itself

### Forces

Force settings control how the graph behaves.

- **Centre force**\
  Pulls notes toward the middle
- **Repel force**\
  Pushes notes away from each other
- **Link force**\
  Controls how strongly connected notes stay together
- **Link distance**\
  Controls the space between connected notes

### How to create connections

Use `[[Note name]]` inside a note to link it to another note.

**Example:** in a note called `Marketing Plan`, type `[[Q2 Campaign]]`

Once links are added, Atlas starts showing relationships between notes visually.

## Dynamic AI Insights

Dynamic AI Insights let you take action on any text you highlight inside a note.

### What you can do

- Summarize key points
- Turn content into To-Dos
- Draft emails directly from notes
- Explain or simplify complex text
- Create meeting recaps
- Enhance or polish writing
- Rewrite in different tones or styles
- Generate creative outputs like poems or alternate versions
- Ask anything related to your highlighted content

### How to use

1. Highlight text inside a note
2. Type what you want Samantha to do
3. The content transforms instantly

<Note>
  Dynamic AI Insights require an internet connection.
</Note>

## Chat with Notes

Chat with your notes to get insights, rewrite content, and turn ideas into action.

### What you can do

- Turn meeting notes into follow-up messages
- Identify decisions, action points, or missing details
- Rewrite content in a clearer or more professional tone
- Break plans into step-by-step actions
- Extract deadlines, tasks, or key information
- Simplify complex ideas
- Brainstorm or expand on your existing notes

### How to use

1. Open any note
2. Tap **Chat with Samantha** in the top-right corner
3. Start chatting with Samantha
4. Ask anything. Samantha understands your note’s context automatically

### Example prompts

```text
Turn this meeting note into a clear follow-up message.

What decisions were made in this note?

Rewrite this idea in a more professional tone.

Find anything I might have missed or unclear here.

Break this plan into step-by-step actions.

Give me a quick brief like I'm about to present this.

What questions should I ask based on this note?

Simplify this so a beginner can understand.

Extract only deadlines and important dates from this.

Convert this into a weekly workflow.
```

Export notes when you need a copy outside MySamantha.

**Available formats**

**How to use**

1. Open a note menu
2. Select **Export**
3. Choose your format

## Public Notes

Make a note public when you want to share it with others using a link.

**How to make a note public in MySamantha**

1. Open the note you want to share
2. Tap the share icon
3. Choose **Share**
4. Toggle **Public** or **Anyone with link** on
5. Tap **Copy link** and send it

**Good for**

- Shared docs and checklists
- Meeting notes and recaps
- Portfolios and templates

<Warning>
  Avoid making notes public if they contain passwords, OTPs, ID numbers, bank details, or anything private or personal.
</Warning>

## Import from Notion

Import your existing Notion content into MySamantha.

### How to use on mobile

1. Open Notes
2. Click the kebab menu
3. Select **Import from Notion**

### How to use on web

1. Go to **Profile**
2. Open **Settings**
3. Navigate to **Imports**
4. Choose **Notion** and **Authorize Access**
5. Select the content you want to import

## Using Notes with Samantha

You can manage notes directly from chat.

**Examples**

- “Create a note from this.”
- “Summarize this note.”
- “Turn this into a to-do.”
- “Open my meeting notes.”
- “Add this to note.”

Samantha only acts when you ask.

## Offline Behavior

When offline, you can:

- Create new notes
- Edit existing notes
- Organize, pin, and label notes

AI features, including Dynamic AI Insights and chat-based note actions, resume once you are back online.

<Tip>
  Notes work best when you capture quickly first, then organize or refine later.
</Tip>
