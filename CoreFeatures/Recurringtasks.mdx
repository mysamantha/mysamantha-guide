Recurring tasks are useful for routines like daily medication, weekly reviews, monthly bills, or annual deadlines. Set the pattern once, and MySamantha keeps the schedule going for you.

## What are recurring tasks?

Recurring tasks help you automate work that happens on a regular schedule.

<CardGroup cols={2}>
  <Card title="Common examples" icon="calendar">
    Daily medication, weekly team meetings, monthly rent, quarterly reviews, and yearly tax filing.
  </Card>

  <Card title="How it works" icon="rotate-right">
    When you complete one recurring task, the next occurrence is created automatically based on the pattern you set.
  </Card>
</CardGroup>

## How to create recurring tasks

<Tabs>
  <Tab title="In mobile app">
    1. Create a new task
    2. Click the **Date** field
    3. Open the **Recurring** tab
    4. Choose the **start date**
    5. Set the **start time** and **end time**
    6. Choose how often the task should repeat:
       - Every day
       - Every week
       - Every month
       - Every year
       - **Custom**
    7. Save the task
  </Tab>
  <Tab title="In web app">
    1. Create a new task
    2. Under **Task Type**, choose **Recurring**
    3. Open **Frequency**
    4. Choose the repeat pattern:
       - Every day
       - Every week
       - Every month
       - Every year
       - **Custom**
    5. Set **Start time** and **Due time** under **Instance Times** if needed
    6. Choose the **List**
    7. Click **Create task**
  </Tab>
</Tabs>

<Tip>
  Use **Custom** when you want a more specific repeat pattern.
</Tip>

## Managing recurring tasks

<AccordionGroup>
  <Accordion title="Completing a recurring task">
    Each recurring task creates the next scheduled task automatically.

    If you don’t complete today’s task, the next one will still appear on the scheduled date. Uncompleted tasks are marked as overdue.
  </Accordion>

  <Accordion title="Editing a recurring task">
    Changes apply to all future occurrences.

    If you change the frequency or interval, the recurrence pattern recalculates from today.
  </Accordion>

  <Accordion title="Ending a recurring task">
    You can choose when the task stops repeating:

    - **Never**
    - **On date**
    - **After several occurrences**
  </Accordion>

  <Accordion title="Deleting a recurring task">
    Deleting a recurring task removes all future occurrences.

    If you only want to remove one occurrence, complete it instead or convert it to a one-time task first.
  </Accordion>
</AccordionGroup>

<Tip>
  Open the **menu (⋮)** and select **Show all recurring instances** to see all upcoming occurrences of a recurring task in one place.
</Tip>

## Tips for setting recurring tasks

<CardGroup cols={2}>
  <Card title="Be specific with times" icon="clock">
    Instead of **Every day**, use **Every day at 9 AM** to make the routine more consistent.
  </Card>

  <Card title="Use weekdays for work tasks" icon="briefcase">
    **Every weekday** is cleaner than listing Monday through Friday separately.
  </Card>

  <Card title="Start simple" icon="sparkles">
    Start with simple patterns like **Every Monday** before using more advanced custom setups.
  </Card>

  <Card title="Use date-based repeats for bills" icon="credit-card">
    For monthly bills, use patterns like **Every 1st** for consistency.
  </Card>
</CardGroup>
