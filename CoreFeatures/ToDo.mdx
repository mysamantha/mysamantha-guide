To Do helps you capture tasks quickly, stay organized, and keep track of what matters. You can create tasks from scratch, use voice, turn notes or chats into tasks, set reminders, and plan your day with Samantha.

<Note>
  To Do works offline. AI-powered actions require an internet connection.
</Note>

## Creating Tasks

You can create tasks in multiple ways:

1. Type directly in To Do
2. Use voice to add a task
3. Ask Samantha to create a task
4. Turn notes, emails, or conversations into tasks

You do not need to fill in every detail right away. You can update tasks later.

## Voice to Task

Use voice when you want to capture a task quickly.

**How to use**

1. Tap the microphone
2. Say your task naturally
3. The task is created with the detected details

## Smart Date Detection

MySamantha can detect dates and times automatically when you type or speak naturally.

**Examples**

- `tomorrow`
- `next Monday`
- `at 5 PM`

You can edit dates anytime.

## Subtasks

<Frame>
  ![Untitled Design (29)](/images/Untitled-design-\(29\).png)
</Frame>

Subtasks help you break a task into smaller steps.

**How to use**

1. Create the main task, the outcome
2. Add subtasks, the steps
3. Tick subtasks, then complete the main task

**Best practices**

- Keep subtasks short
- Start each with a verb like Draft, Review, Send
- Order them if sequence matters

**Examples**

- Prepare weekly report → Pull data → Draft → Review → Send
- Grocery run → Milk → Eggs → Rice

## Priorities

Use priorities to highlight what matters most.

**How to use**

1. Assign a priority to any task
2. Review higher-priority tasks first

## Reminders

Set reminders so tasks do not slip.

**How to use**

1. Add a reminder to any task
2. Get notified at the right time
3. Snooze or reschedule if needed

## Filters and Search

Use filters and search to find tasks faster.

**You can**

- Search tasks by meaning
- Filter by priority or list

This is useful when you remember the task but not where it lives.

## Progress Tracking

Track your work over time by reviewing:

- Completed tasks
- Overdue tasks
- Archived tasks

This helps you understand progress and workload.

## Archiving Tasks

Archive tasks you do not want in your active view.

**How to use**

1. Archive tasks you’re not working on now
2. Restore them anytime

## Using To Do with Samantha

You can manage tasks directly from chat.

### Example prompts

```text
Add a task to submit the report tomorrow.

Change this task to high priority.

Move my meeting prep to next week.

What are my top tasks today?

Ask Samantha to move, reschedule, or adjust tasks.
```

Samantha only acts when you ask.

## Plan your day with Samantha

Samantha can help you decide what to focus on.

### Example prompts

```text
What should I do today?

What is overdue?

What are my top tasks right now?

Help me plan my day.

Show me what I can finish quickly.
```

This makes To Do more than a list. It helps you actually move through your day.

## Offline Behavior

When offline, you can:

- Create tasks
- Edit tasks
- Change priorities
- Mark tasks as done
- Reorder lists

Your changes sync automatically once you are back online.

<Tip>
  To Do works best when you capture quickly first, then organize priorities and reminders after.
</Tip>
