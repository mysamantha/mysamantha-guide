Connect Cloudflare so Samantha can help you work across web infrastructure, domain setup, and site operations without switching context.

**What Cloudflare integration helps you do**

- Check zones or domains
- Review DNS records
- Inspect basic site configuration
- Understand or organize web infrastructure info
- Monitor and summarize setup details
- Assist with website-related operational tasks
- Keep infrastructure work connected with notes, tasks, and planning

**Connect Cloudflare**

1. Open **MySamantha**

2. Go to **Settings**

3. Select **Integrations**

4. Choose **Cloudflare**

5. Sign in and approve access

**Work with Cloudflare using Samantha**  

Once connected, you can ask Samantha to review domains, check DNS records, summarize configuration details, help with website operations, and connect infrastructure work with your broader planning workflow.

<Accordion title="Example prompts">
  Show my Cloudflare zones

  List DNS records for my domain

  Check the setup for \<websitename\>

  Summarize my Cloudflare configuration

  Help me review my domain settings

  Turn this infra work into a task list
</Accordion>
