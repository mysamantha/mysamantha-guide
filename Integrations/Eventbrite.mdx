Connect Eventbrite, so Samantha can help you work across events, registrations, and follow-ups without switching contexts.

## **What Eventbrite integration helps you do**

- Look up your events
- Check event details
- Track attendees or registrations
- Pull event summaries
- Organize follow-up work after an event
- Turn event info into notes, tasks, or reminders
- Draft promo or update messages based on event details

## **Connect Eventbrite**

1. Open **MySamantha**

2. Go to **Settings**

3. Select **Integrations**

4. Choose **Eventbrite**

5. Sign in and approve access

6. Disconnect anytime from Settings

## **Work with Eventbrite using Samantha**  

Once connected, you can ask Samantha to find events, review event details, check registrations, summarize active events, turn event information into action items, and help draft follow-up or attendee messages.

<Accordion title="Example prompts">
  Show my upcoming Eventbrite events

  Get details for this event

  How many people registered?

  Summarize my active events

  Turn this event into a task checklist

  Draft a reminder message for attendees
</Accordion>
