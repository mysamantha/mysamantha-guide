Connect GitHub so Samantha can help you work across repositories, issues, and pull requests without switching context.

**What GitHub integration helps you do**

- List your repositories

- Find issues or pull requests

- Create issues

- Review repo activity

- Summarize open work

- Draft issue descriptions, PR summaries, or update messages

- Keep GitHub work connected with notes, tasks, and planning

- Track progress across product and engineering

**Connect GitHub**

1. Open **MySamantha**

2. Go to **Settings**

3. Select **Integrations**

4. Choose **GitHub**

5. Sign in and approve access

**Work with GitHub using Samantha**  

Once connected, you can ask Samantha to review repositories, find open work, create issues, summarize activity, and help draft updates using your existing project context.

<Accordion title="Example commands">
  Show my GitHub repositories

  List open pull requests

  Create a GitHub issue for homepage copy cleanup

  Find issues about pricing

  Summarize activity in this repo

  What changed recently in this project?
</Accordion>
