Connect HubSpot so Samantha can help you work across contacts, companies, deals, and follow-ups without switching context.

## **What HubSpot integration helps you do**

- Find contacts, companies, or deals
- Look up a company before a call
- Create or update contacts
- Add notes to records
- Track deal status
- Pull quick summaries from CRM data
- Draft follow-ups using HubSpot context
- Keep sales and admin work connected across HubSpot, email, notes, tasks, and calendar

## **Connect HubSpot**

1. Open **MySamantha**

2. Go to **Settings**

3. Select **Integrations**

4. Choose **HubSpot**

5. Sign in and approve access

6. Disconnect anytime from Settings

## **Work with HubSpot using Samantha**  

Once connected, you can ask Samantha to find contacts, review deal status, update records, add notes, summarize CRM activity, and help draft follow-ups based on HubSpot context.

<Accordion title="Example prompts">
   Find the HubSpot contact for Rahul

  Show me open deals closing this month

  Create a contact for \[name\] with this email

  Add a note to this company record

  Summarize my active deals

  What’s the latest status on this lead?
</Accordion>
