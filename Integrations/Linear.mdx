Connect Linear, so Samantha can help you manage product and engineering work without switching context.

## **What Linear integration helps you do**

- List your assigned issues
- Find issues by keyword
- Create new issues from ideas, messages, or notes
- Check what is in progress, in backlog, or blocked
- Summarize project status
- Turn discussions into actionable tickets
- Draft clearer issue titles and descriptions
- Keep Linear work connected with your notes, tasks, and calendar

## **Connect Linear**

1. Open **MySamantha**

2. Go to **Settings**

3. Select **Integrations**

4. Choose **Linear**

5. Sign in and approve access

6. Disconnect anytime from Settings

## **Work with Linear using Samantha**  

Once connected, you can ask Samantha to find issues, review status, create tickets, organize backlog work, turn conversations into tasks, and help write clearer issues using your existing context.

<Accordion title="Example prompts">
  Show my assigned Linear issues

  Find issues about homepage

  Create a Linear issue for tighten pricing section copy

  What’s blocked right now?

  Summarize my active Linear work

  Turn this note into Linear issues
</Accordion>
