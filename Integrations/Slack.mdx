Connect Slack so Samantha can help you work across messages, threads, and team updates without switching context.

## **What Slack integration helps you do**

- Send messages
- Read or summarize channels and threads
- Find specific updates
- Pull out decisions and action items
- Turn Slack conversations into notes or tasks
- Draft replies faster

## **Connect Slack**

1. Open **MySamantha**
2. Go to **Settings**
3. Select **Integrations**
4. Choose **Slack**
5. Sign in and approve access

## **Work with Slack using Samantha**

\
Once connected, you can ask Samantha to send messages, summarize conversations, find updates, extract action items, create notes or tasks from Slack, and help draft replies.

<Accordion title="Example prompts">
  Send a message to myself in Slack saying test from Samantha

  Summarize my recent Slack messages

  Find messages about homepage copy

  Draft a Slack update about today’s work
</Accordion>
