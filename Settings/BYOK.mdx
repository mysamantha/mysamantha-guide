BYOK stands for **Bring Your Own Key**.

It lets you connect your own API keys so Samantha can use them for supported features such as assistant and transcription workflows.

## Why use BYOK

BYOK gives you more control over how certain features are powered.

You may want to use it if you want to:

- Use your own provider account
- Manage usage on your side
- Choose which key powers supported features
- Keep the assistant and transcription setup under your own configuration

## What BYOK can be used for

Depending on what is supported in your workspace, BYOK can be used for:

- assistant features
- transcription features

## Assistant

BYOK can be used for supported assistant workflows where Samantha relies on an API key to generate responses or help you complete tasks.

This is useful if you want assistant usage to run through your own provider setup.

## Transcription

BYOK can also be used for supported transcription workflows.

This allows Samantha to use your own transcription key for features that process audio and generate transcripts.

Your transcription behavior may also depend on your preferences.

For example, if you enable **Use long transcription key for short transcription too** in **Preferences**, short audio may also use that setup.

## How to add your key

1. Open **Settings**
2. Select **BYOK**
3. Paste the API key for the feature you want to use
4. Save your changes

## Before you start

Make sure that:

- Your API key is valid
- Your provider account is active
- The key has access to the feature you want to use.[For more](https://mysamantha.ai/blog/bring-your-own-api-keys-to-mysamantha)

<Tip>
  - Keep your API keys private
  - Double-check keys before saving
  - Review your preferences after setup, if transcription behavior depends on them
</Tip>
