---
title: "Slash Commands"
description: "Create, update, and manage reusable prompt shortcuts with Samantha."
---

Slash Commands let you save reusable prompt shortcuts for things you do often.

Instead of repeating the same instruction every time, you can create a command and run it with a short name.

## How Slash Commands work

You can manage Slash Commands in two ways:

- chat with Samantha to create, update, or delete a command
- open Settings to review and delete existing commands

## Why use Slash Commands

Slash Commands are useful for repeat workflows such as:

- meeting summaries
- follow-up emails
- daily planning
- writing help
- recurring team processes

## Common examples

You might create commands like:

- `/daily-plan`
- `/meeting-summary`
- `/followup-email`
- `/content-ideas`

## Create a Slash Command

Chat with Samantha and describe the shortcut you want to save.

## Edit a Slash Command

If you want to change what a command does, chat with Samantha and ask to update it.

## Delete a Slash Command

You can delete a Slash Command in either of these ways:

- chat with Samantha and ask to remove it
- open **Settings** and delete it from your saved commands

## Tips

- Use short, clear command names
- Create commands for workflows you repeat often
- Keep each command focused on one job
- Remove commands you no longer use
