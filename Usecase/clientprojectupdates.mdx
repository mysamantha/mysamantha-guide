title: "Client / Project Updates"
---

Keep clients and stakeholders informed without spending hours writing updates.

Samantha helps you pull together project progress, blockers, next steps, and open asks so you can send clear updates faster and keep communication consistent.

## **Best for**

- professionals managing multiple clients or projects
- people who spend too much time writing status updates
- teams that want clearer stakeholder communication
- anyone who wants a more reliable update rhythm

## **What you’ll get**

- status updates drafted from your notes, tasks, and emails
- a clearer structure for progress, blockers, and next steps
- faster follow-up on client questions or feedback
- reminders to send updates on a regular cadence
- better visibility into which projects need communication

## **How client and project updates work**

### **Step 1: Gather the context**

Start by giving Samantha the project context you already have.

**For example:**

```text

Draft a weekly update for the Acme project.

Here’s what happened this week on IndigoTech.

Summarize this project for a client update.
```

You can share:

- rough notes
- task progress
- recent meetings
- email threads
- bullet points from the week

You do not need to organize everything first. Samantha can help turn rough input into a usable update.

## **Step 2: Draft the update**

Once Samantha has the context, she can turn it into a clear stakeholder update.

She can help structure it into sections like:

- completed work
- work in progress
- blockers
- next steps
- open questions or approvals needed

This makes updates easier to read and easier to send.

## **Step 3: Refine the message**

If needed, you can adjust the draft based on tone, length, or audience.

**For example:**

```text

Make it shorter, 5 bullets max.

Keep it professional and concise.

Add a note that we need their feedback on the design by Friday.
```

This is useful when different clients or stakeholders need different levels of detail.

## **Step 4: Turn replies into follow-up actions**

Once the update is sent, Samantha can help turn incoming feedback into next steps.

**For example:**

```text

Pull all open action items for the Acme account.

Create tasks from this client feedback.

Remind me to follow up if they do not reply by Friday.
```

This helps project communication stay connected to execution.

## **Step 5: Keep updates consistent**

Samantha can also help you stay on a regular update rhythm.

**For example:**

```text

Create a reminder to send status updates every Friday at 4 PM.

What projects have not had an update sent recently?

Flag projects with no recent activity.
```

This is useful when you want updates to happen proactively instead of only when someone asks.

### **Example prompts**

```text

Draft a client update email for the Acme project based on this week’s progress.

Summarize the last 7 days on the IndigoTech project in 5 bullets.

What projects have not had an update sent in the last week?

Create a reminder to send status updates every Friday at 4 PM.

Draft a message to the client flagging a delay in the timeline.

Pull all open action items for the Acme account.

Write a project kickoff summary to share with the client.

What is blocked across my active projects right now?
```

## **Tips for better results**

<Tip>
  - Keep a running note for each project
  - Capture updates as they happen instead of all at once
  - Ask Samantha to include blockers and approvals clearly
  - Set recurring reminders for regular update cadences
  - Use project updates to turn feedback into follow-up tasks
</Tip>
