---
title: "Install and Configure the MySamantha Browser Extension"
description: "Save useful web content to your Personal Workspace without copying it into Notes by hand. Set up the extension once, then use it whenever you need it."
---

## **Install the extension**

1. Open [MySamantha in the Chrome Web Store](https://chromewebstore.google.com/detail/mysamantha/mmchfpmipfelinkedmmhbahdgjmnlboo).
2. Select **Add to Chrome**, then confirm the installation.

## **Sign in and pin it**

1. Open the MySamantha extension and sign in to your account.
2. To keep it handy, open Chrome’s extensions menu and pin MySamantha to the toolbar.

## **Set site access**

1. If Chrome asks for permission to access a webpage, review the prompt and allow access when you want to use MySamantha on that page.
2. To change access later, open Chrome’s extensions settings, select MySamantha, then adjust its site access.

## **Test the extension**

1. Open a webpage and select the MySamantha icon.
2. Try saving selected content or the full webpage as a section, creating a new note, or adding content to an existing note.

## **Fix common setup issues**

1. If you can’t see the icon, open Chrome’s extensions menu and pin MySamantha.
2. If the extension doesn’t work on a page, check its site access and reload the tab.
3. If you’re signed out, open the extension and sign in again.

For saving webpages, see **Capture from the web**. For meeting recordings, see **Record a meeting**.
