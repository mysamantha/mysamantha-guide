## **Table**

A Table is a basic grid for displaying information. It starts with three columns, two rows, and a header.

1. Open a note and place the cursor where you want the Table.
2. Type `/` and select **Table**.
3. Click a cell to enter information.

### **Table menu options**

1. **Select table:** select the whole Table.
2. **Copy table:** copy it.
3. **Wrap or unwrap cells:** show long text on multiple lines or keep it on one line.
4. **Use fixed layout:** keep column widths fixed.
5. **Reset widths:** restore the default column widths.
6. **Fill color** and **Borders:** change the Table’s appearance.
7. **Vertical alignment:** position cell content at the top, middle, or bottom.
8. **Insert row above/below** or **column left/right:** add rows or columns.
9. **Exit table fullscreen:** return to the note.

## **Database**

A Database is a structured table for keeping records. Each row is an item, and each column stores a detail about it.

1. Open a note and place the cursor where you want the Database.
2. Type `/` and select **Database**.
3. Add columns, choose a property type for each, then add rows.
4. Choose a view: **Table**, **Board**, **Chart**, **Gallery**, **List**, or **Calendar**.

### **Database property types**

1. **Text, Long Text:** short or longer written content.
2. **Number, Currency, Percent, Duration:** quantities, money, percentages, or time spans.
3. **Select, Multi Select:** choose one option or several.
4. **Status, Checkbox:** track a stage or a yes/no value.
5. **Date, Date + Time:** store a date or a date and time.
6. **URL, Email, Phone:** store links and contact details.
7. **Rating:** give an item a score.
8. **Formula:** calculate a value from other columns.
9. **Relation:** link a row to another Database.
10. **Lookup:** show information from a related row.
11. **Created Time, Last Edited Time:** automatically record when a row was created or changed.

### **Database menu options**

1. **Open row editor:** view or edit a row’s details.
2. **Wrap cells:** show longer cell content on multiple lines.
3. **Export CSV:** export the Database as a CSV file.
4. **Create form:** collect responses in the Database. Choose who can respond, then share the form.
5. **Duplicate database:** make a copy.
6. **Delete database:** remove it from the notes.

<Note>
  A Database supports up to 2,000 rows. Samantha can read and edit it, and it can power a Home applet.
</Note>
