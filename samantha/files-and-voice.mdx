## **Add files to a chat**

1. Select **Upload from device**, **Take a photo**, or **From Library**. Type `@` to open the Library.
2. Add images, PDFs, Word, PowerPoint, Excel, text, or code files. Audio and video aren't supported in chat.
3. Files can be up to 100 MB. Images are limited to 25 MB per message.
4. Wait for the file to finish reading before asking Samantha about it.

## **Manage files in the Library**

1. Browse or filter Files, Notes, To-dos, Applets, and Chats.
2. Preview, download, rename, or delete a file.

<Info>
  Deleting a file removes it from every chat.
</Info>

## **Talk to Samantha**

1. Select **Dictate** or press **Ctrl+Space**. You can also hold Space in an empty composer to record.
2. Choose **Discard**, **Stop and transcribe**, or **Transcribe and send**. Recordings can be up to 60 minutes.
3. Allow microphone access. Only one browser tab can record at a time.

<Info>
  Voice transcription is billed separately. A ChatGPT subscription doesn’t cover it.
</Info>
