---
title: "Sync and backup "
description: "Back up To-do lists to Todoist and link Microsoft To Do items to their source chats."
---

## **Back up a list to Todoist**

1. Connect Todoist to MySamantha.
2. Open the list you want to back up.
3. Select **Backup to Todoist**.
4. Repeat for each list. 

<Note>
  This is a one-way backup, not a two-way sync.
</Note>

## **Link Microsoft To Do items to a conversation**

1. Go to **Settings > Preferences > General**.
2. Turn on **Microsoft To Do backlinks**.
3. When Samantha creates an item in Microsoft To Do, it includes a link to the conversation it came from.
4. Open the link to return to that conversation.

<Note>
  To-do items do not sync to Calendar.
</Note>
