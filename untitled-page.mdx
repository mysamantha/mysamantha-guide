---

## **Create an applet**

1. Select **New applet**, or ask Samantha in chat to create one.
2. Choose what you want to track and where its data is saved.
3. Set its name, icon, color, goal, display style, and reminders.
4. Add it to Home. If you started in chat, select **Add to Home** on the preview.

## **Use an applet**

1. Select **Log entry** to add information to its Table.
2. Select **Ask Samantha about this applet** to discuss its data.
3. Applet reminders are sent as YouDos.

## **Browse the marketplace**

1. Browse **Featured**, **Your applets**, or **Public applets**.
2. Browse categories such as **General**, **Fitness**, **Sleep**, and **Finance**.
3. Select **Add to Home** to use an applet. Some include starter data and a guide.
4. Select **Create a personalized applet** to start creating one in chat.

## **Share an applet**

1. Open **Your shares** to find links to applets, streaks, and personality cards.
2. Copy a link to share it, or revoke the link to stop sharing.
3. Visitors can select **Track this** on a shared card to add it to their own Home.
